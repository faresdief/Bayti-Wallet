# Bayti Wallet | مدير المصاريف

مدير مصاريف البيت بالجنيه المصري: سجّل مصاريفك، حدّد ميزانيات، وتابع إنفاقك بالرسوم البيانية. A household expense manager in Egyptian Pounds: record expenses, set budgets, and track your spending with charts.

**Live demo:** https://faresdief.github.io/Bayti-Wallet/

## المميزات | Features

- تسجيل المصاريف حسب الفئة، مع حدود إنفاق لكل فئة. Expenses by category, with per-category spending limits.
- ميزانية إجمالية ومتابعة الإنفاق مقارنة بالحدود. An overall budget with spending tracked against limits.
- مصاريف متكررة للفواتير والالتزامات الثابتة. Recurring expenses for fixed bills and commitments.
- رسوم بيانية: الإنفاق حسب الفئة، الاتجاه الشهري، ومقارنة الفئات. Charts: spending by category, monthly trend, and category comparison.
- واجهة عربي وإنجليزي، وضع ليلي، وألوان قابلة للتخصيص. Arabic and English interface, dark mode, and customizable colors.
- نسخ احتياطي كامل: تصدير واستيراد JSON، نسخ للحافظة، وتصدير CSV. Full backup: JSON export and import, copy to clipboard, and CSV export.
- كل البيانات محفوظة محليًا في المتصفح (localStorage)، من غير حساب ولا سيرفر. All data stays in your browser (localStorage); no account, no server.

## التشغيل | Run

ملف واحد `index.html`: افتحه في المتصفح وخلاص. A single self-contained `index.html`: just open it in a browser.
